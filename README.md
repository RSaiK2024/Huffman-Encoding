# Huffman Encoding (C)

## Description
Implementation of Huffman Encoding and Decoding using C. 
Uses greedy algorithm with binary tree construction based on character frequencies.

## Features
- Builds Huffman Tree dynamically
- Generates prefix codes
- Encodes input data
- Decodes encoded data

## Concepts Used
- Data Structures (Trees, Linked Lists)
- Greedy Algorithms
- Memory Management in C
